      Import from Amazon

      Amazon has no way for other sites to read your orders, so this uses a bookmark that you tap while you're on your Amazon orders page. It reads each item's name, photo, order date, order number and price, page by page, then brings them here so you can choose what to add. It only sends them to this page.

      1. Add the bookmark. On a computer, drag this button to your bookmarks bar: ＋ Things I own
        On a phone: , bookmark any page, edit that bookmark and paste the code as its address.
      2. Open your orders on Amazon, signed in: amazon.com.tr → Siparişlerim.
      3. Tap the bookmark on each page of your orders. Every tap adds that page's items to a list it keeps, and duplicates are skipped. When you've been through all the pages, tap Open in Things I own in the box at the top of the Amazon page to see your items here. Download as file also works: open that file with Import here.

      Photos are shown from Amazon's servers and sync with the rest of the details. Items you've already imported are skipped.
